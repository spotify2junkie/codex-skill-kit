# 分组推荐与图片规范

## 排名判断

分组由本次用途决定，不固定下面的分类或权重。

| 用途示例 | 默认优先考虑 | 需说明的取舍 |
| --- | --- | --- |
| 通勤兼轻松跑 | 舒适、透气、合脚、稳定与弯折 | 回弹、重量、鞋头空间 |
| 稳定支撑 | 支撑结构、底座、舒适与抓地 | 厚重、僵硬、回弹、闷热 |
| 速度训练 | 轻快、配速适应、抓地与耐用 | 楦型、板材刚性、鞋舌 |
| 公路竞赛 | 目标赛距与配速、适配、滚动与稳定 | 极端几何、耐用、通用性 |
| 城市步行 | 长走舒适、抓地、耐磨与气候 | 防水膜、透气、重量 |
| 徒步 | 地形、负重、支撑、抓地与防护 | 重量、闷热、技术地形适配 |
| 运动后休闲 | 穿脱、包头/夹趾偏好与气候 | 不作恢复疗效排名 |

宽脚、怕闷、只走路、追求速度、重装徒步等条件可改变首选。给出条件提示，而不是宣称存在适合所有人的冠军。羽毛球等场地鞋需对应的原始测评，不将跑鞋排名迁移过去。

每组按推荐顺序列最多三双；少于三双按实际数量。证据不足时可少排，必须在 ranking_note 解释。每个推荐写“适合谁／为什么 + 主要取舍”。没有当前可比价格就不做性价比冠军。

## 图二：分组 Top 3

Top 1 用橙色“首选”，Top 2 白色，Top 3 青色。每组显示排序标准、推荐理由和取舍。其他鞋列在“其他备选（未排序）”。两图共用鞋款 ID 和分组。

生成式图片依据脚本导出的 top3.prompt.txt，避免手抄鞋名导致版本漂移。只放定性建议，不放需精确还原的实验数值。没有图像生成能力时，代码版 top3.svg 是可用的直接输出。

用户要完整排序时再根据证据展开，不凭微小数值差异强行给第四至最后一名。选择性推荐是基于证据的判断，不是销量或来源方排名。

## 图片验收

1. 两张主图都已生成，不能只交提示词。
2. 两图鞋款集合等于确认鞋单；类别、变体、缺失值一致。
3. Top 3 顺序和模型 ID 一致；理由与取舍能追到原始来源。
4. 没有虚构销量、价格、健康收益或总冠军。
5. Credit to SOLE鞋履 清晰可见，数据来源另列。
6. 中文与长型号可读，无裁切、乱码、重复或遗漏；示意鞋图已标注。
