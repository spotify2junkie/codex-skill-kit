# 鞋款双图选购指南

把用户当次鞋单变成两张主图。任意品牌、型号、数量均可；历史 HOKA 50 款仅为案例。

1. **完整鞋款对比图**：全部鞋款按用途分组，展示统一口径的参数、用途、缺失值。
2. **分组 Top 3 推荐图**：每组明确 1 / 2 / 3、首选、推荐理由和主要取舍；其余鞋列入“其他备选（未排序）”。

用户明确只要简表或单图时遵从当次要求。量大可附分页，但总览不得漏鞋。

## 署名

两张图、生成提示词和来源页都显示 **Credit to SOLE鞋履**。
配套说明：**参数决策卡与表达方式的灵感来源；本次数据核验与推荐独立整理。**

实验数据另署实际来源。不要把 SOLE鞋履说成本次排名作者、实验室、合作方或背书方，不编造其账号链接，不复制头像或平台界面。

## 确定本次鞋单

- 接受鞋名、链接、截图和混合输入，保留英文正式型号。GTX、SR、Wide、男女款和代数不能互相替代。
- 用户给具体清单就保留原清单；只给品牌且未指定数量，可选 6–10 款代表型号并说明覆盖范围。指定数量时尽量覆盖，但不把不同配色当不同型号。
- 型号不清先查证，仍无法确认则标为待确认，先完成其余部分。
- 保留本次排除条件。徒步与越野跑分别识别；不要把某次的“排除越野”变成所有请求的规则。
- 现款、往代、特殊用途分别注明。缺乏可核验销量依据时写“选购对照”，不可把“50 款”伪称“销量 Top 50”。
- 分组随用途变化。速度训练与公路竞赛必要时拆组；两张图必须使用相同分组。

## 核验来源与数据

先读 [references/data-and-schema.md](references/data-and-schema.md)。

1. 联网读取每款原始实验室测评，优先 RunRepeat 的 **Lab test results** 及测试方法；官方页面核验型号、结构、用途、防水和官方规格。截图只作为线索。
2. 记录原始 URL、核验日期、性别/尺码、方法及测量部位。同列使用同口径实测；官方值另列，不混进实测。
3. 固定参数：鞋款｜单只重量 g｜室温主泡棉 AC｜后跟吸震 SA｜后跟回弹 %｜前掌/后跟鞋底厚度 mm｜坡差 mm。
4. 不换算 AC / HA / HC，不用类别平均数、其他代数或营销描述补值。找不到同口径数值填 null，显示为“—”。
5. 部件读数与汇总冲突时，检查前掌/后跟、平均值/单鞋、方法新旧；优先明确标注部位的汇总行。同口径仍冲突就记下差异，不能任意选一个。
6. 不同样本/方法保留独立参数子表，不伪装成可直接横比。来源不明的用户实测单独标注。
7. 验证后跟减前掌与坡差一致，允许四舍五入约 0.2 mm。

## 给出分组 Top 3

读 [references/ranking-and-images.md](references/ranking-and-images.md)。

- 每组先写默认用途和排序标准，再结合用途适配、脚感、稳定、抓地、耐用及主要局限判断。不要按一个数字、站点总分或代数机械排序。
- 排名注明“我的推荐顺序 / 基于资料的选购判断”，区别于销量榜、来源方排名或绝对性能榜。
- 每个入选项写有证据的推荐理由和主要取舍。名次通过鞋款 ID 引用同一份数据，避免版本串用。
- 只有 1–2 双就给 Top 1–2；证据不足时少排并说明原因，不凑数、不添加鞋单外型号。
- 没有体重、预算等个人信息时，写明用途假设继续出图；会改变顺序的条件写在组内。
- 需要性价比时才查当地当前实付价及限制，没有可比现价不宣称最划算。
- 软、吸震、回弹是不同概念。实验回弹不是跑步经济性，不把参数转成护膝、治疗、恢复疗效或防伤承诺。场地鞋使用对应证据，不能套用跑鞋结论。

## 生成两张图

把定稿数据写成一个 JSON。运行随 skill 附带的零依赖 Node.js 脚本（Node.js 18+）：

```bash
node scripts/build_shoe_guide.cjs guide.json OUTPUT_DIRECTORY
```

输出：

- `comparison.svg`：完整参数对比长图，数值由代码排版。
- `top3.svg`：精确排版的分组推荐图，可直接交付或用作生成式图片参考。
- `sources.html`：所有鞋款、来源、口径、推荐理由/取舍和署名。
- `top3.prompt.txt`：从同一数据生成的推荐图定稿提示词。

SVG 是可缩放图片；中文显示需要环境有中文字体。需要 PNG 时用可用的浏览器或 SVG 渲染器从 SVG 导出，检查中文和裁切，不用生成式工具重绘精确数值。

用户要求“创建图片”或修改已有生成图片时，使用当前环境的图像生成工具，把 `top3.prompt.txt` 的定稿内容生成推荐图。编辑先查看参考图，再按实际接口传入。只把定性文案用于生成式推荐图，不复制实验数字进去。新推荐图替代代码版推荐主图，不把同图的格式变体算作第三项交付。工具名和文件保存方式以当前环境实际能力为准。

缺少图像工具时可交付代码版 SVG 并说明；没有执行工具时给出明确限制，不能声称已产出图片。脚本只做结构和一致性校验，不联网查证来源，也不自动决定排名。

## 复核与交付

- 全鞋单在两图中都完整出现；组别一致，其他备选未静默删除。
- 型号、变体、单只重量、样本、单位和测试部位正确；缺失值和冲突保留。
- 每组名次准确，对应理由与取舍有来源；插图若为示意则写“鞋图为示意”。
- 打开图片检查中文、数字、长型号、边界及署名。生成式图片逐项核对，不以精美代替正确。
- **Credit to SOLE鞋履** 在两张主图与来源页清晰可见。
- 通过当前环境支持的方式保存并交付两张图，附来源页和少量选购要点；生成工具自动保存的图片遵守其保存规则。
